# Paseo에서 확인한 장점과 적용 시의 제한

조사일은 2026-11-09다. 공식 최신 안정판 v0.15.3과 main 소스를 구분했다. `소스`는 구현을 읽었다는 뜻이고 `공식 문서`는 제품이 설명하는 동작이다. 어느 쪽도 이번 조사에서 실제 앱 실행을 통과했다는 뜻은 아니다.

## 사용자가 언급한 장점의 의미

| 항목 | 확인한 내용 | 판단 |
|---|---|---|
| 경량·빠른 사용성 | 스트림 묶기, 변경 없는 행 재사용, 가시영역 렌더링, 사용 중인 데이터 중심 구독 구조가 있음 | 반응성을 설명하는 근거다. Orca보다 빠르다는 동일 조건 벤치마크는 하지 않음 |
| 에이전트 관리 | workspace, 부모·자식 관계, 상태별 목록, 작업 중 지시, 프로필, 결과 수집이 연결됨 | Workbench의 문서별 AI와 메인 채팅 오케스트레이션을 발전시킬 직접적인 참고 |
| 모바일·다기기 | iOS·Android·웹·데스크톱 클라이언트가 호스트 daemon에 연결. relay·직접 연결·데스크톱/CLI SSH 경로 | 휴대폰에서 연구실 PC와 노트북의 실행을 관리하는 방향에 적합 |
| daemon | UI와 에이전트 실행을 나누고 headless 서버 실행 가능 | 앱 Quit, daemon 재시작, OS 절전을 서로 구분해야 함 |
| 채팅·이미지 | 공통 Markdown 표현, 작업 기록 묶기, 로컬 이미지 읽기·캐시·확대 보기, 코드·표·파일 연결 | 가장 먼저 사용감 개선으로 전달할 가치가 큼 |

기본 구조는 [Getting started](https://paseo.sh/docs), 연결 방식은 [Connectivity](https://paseo.sh/docs/connectivity), 대화 처리의 설계 근거는 [Agent stream performance](https://github.com/getpaseo/paseo/blob/1fff127f45b11c1c9c573fbbd12791673004c912/docs/agent-stream-performance.md)에 있다.

## 그대로 가져오면 기대와 달라지는 부분

1. **설치 용량과 반응성을 구분한다.** Paseo 데스크톱은 Electron이다. v0.15.3 Windows x64 설치 파일은 GitHub 자산 기준 145,569,446 bytes, 약 145.6 MB다. 통합 설치 파일은 291,042,653 bytes다. 설치 후 크기·음성 모델·메모리는 이 숫자로 알 수 없다. [릴리즈 자산](https://github.com/getpaseo/paseo/releases/tag/v0.15.3).
2. **main의 최적화가 출시판에 전부 있지는 않다.** 대조한 native 목록 구현은 v0.15.3의 inverted FlatList와 main의 정방향 LegendList가 다르다. main 구현을 즉시 안정판으로 간주하지 않는다.
3. **앱 Quit 후 유지가 항상 기본은 아니다.** 확인한 데스크톱 설정의 `keepRunningAfterQuit` 기본은 false다. 운영체제별 창 닫기와 앱 Quit, 자신이 시작한 daemon인지 여부를 구분해야 한다.
4. **재시작 복구는 별도 기능이다.** v0.15.0의 터미널 유지에는 업그레이드 경로·Windows 설치 예외가 있고, 에이전트 재개는 기본 꺼짐이다. 중단된 작업에 후속 프롬프트를 보내는 복구와 프로세스가 살아 있는 상태는 다르다.
5. **브라우저에는 데스크톱 호스트가 필요하다.** Paseo daemon이 보이는 브라우저 자체를 실행하는 구조가 아니다. Lightpanda의 독립 백그라운드 조사 기능은 여전히 별도로 가치가 있다. [브라우저 구조](https://paseo.sh/docs/browser).
6. **전송 암호화와 기기별 권한 철회·push 보호는 별개다.** 기존 코드를 재사용할 때 연결 삭제를 원격 권한 폐기와 혼동하지 않는다. 세부 근거는 [검증 범위](06-evidence.md)에 있다.
7. **한국어·모바일 완성도를 따로 본다.** 기본 로컬 STT는 영어 모델이다. 모바일 검색·선택·SVG·Mermaid에는 플랫폼별 제한이 있다. 공식 스토어 이미지는 실제 배치의 참고이며 실성능 측정 자료는 아니다.

Paseo의 장점은 충분히 도입할 가치가 있다. 다만 “Paseo가 가장 좋다”는 일반 순위는 이번 조사의 결론으로 삼지 않는다. 우리 제품의 프로젝트 노트·볼트 검색·전체 오피스 편집은 별도의 강점과 요구이며 함께 보존해야 한다.
