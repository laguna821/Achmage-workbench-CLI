## 권고한 도입 순서

1. 대화 가독성·이미지·결과물 개선을 먼저 제공한다.
2. 메인 세션과 하위 작업의 상태·후속 지시·승인을 한곳에서 다룬다.
3. 기존 실행 서버를 UI와 분리하고, 문서 작업의 권한도 화면 접속과 분리한다.
4. 기기 등록과 재접속을 완성한 다음 휴대폰에서 두 대 이상의 컴퓨터를 관리한다.
5. 네이티브 모바일 알림을 추가한다. 작업 공간 서비스·음성·예약·플러그인은 각각 별도 후보로 검증한다.

Paseo의 소스 조사 기준은 main `1fff127f45b11c1c9c573fbbd12791673004c912`다. 공식 최신 안정 릴리즈는 확인 시점에 v0.15.3, `d91ae138cb931447635e94296023414a58bedcc5`였다. 두 이력이 갈라져 있으므로 main의 모든 기능을 출시판 기능으로 표시하지 않는다.

Paseo와 Orca를 같은 장치·같은 작업으로 실행해 우열을 측정하지 않았다. 가독성과 응답성에 대한 권고는 코드·공식 화면·기능 구조를 바탕으로 한 설계 판단이다.
