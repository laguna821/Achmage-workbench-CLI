## 2. 사이드바 = 두 칸 내비게이터 (갈래 `feat/navigator`)

### 2.1 배치

```
┌ 새 세션 · 찾기 · 홈 (지금처럼) ──────────────┐
│ 탐색 칸                │ 목록 칸              │
│ ▾ 지금                 │ 강의 · 12      + ⧉ ⇅ │
│ ▾ 바로가기             │ [거르기…]            │
│ ▾ 프로젝트             │ ── 고정 ──           │
│   ▸ 강의        3 · 9  │ 가을 특강     진행중 │
│   ▸ 연구        2      │  루브릭을 특강에…    │
│   ▸ 행정         1      │  10월 29일 · #강의   │
│ ▾ 태그                 │ ── 이번 주 ──        │
│ ▾ 보기                 │ …                    │
│ ▾ 볼트 Achmage  1 · 11 │                      │
└────────────────────────┴──────────────────────┘
```

- **두 칸**: 넓은 창의 기본. 칸 사이 막대로 너비를 바꾸고 기억한다.
- **위아래**: 좁은 창의 기본(NN의 vertical split). 탐색 칸 위, 목록 칸 아래.
- **한 칸**: 목록 칸 없이 지금의 트리(폴더 → 프로젝트 → 세션). 예전 방식을 원하는 사람용이다.
- 사이드바 머리의 단추와 ⋯ 메뉴로 바꾼다. 사이드바 전체 숨기기는 지금 그대로다.
- 섹션 머리(지금·바로가기·프로젝트·태그·보기·볼트)는 모두 접히고, 접힌 상태를 기억한다(볼트 한 줄 접기와 같은 모양).

### 2.2 탐색 칸: 프로젝트 폴더

- **맨 위 "프로젝트" 줄 = 볼트 루트.**
  - 고르면 폴더 밖 프로젝트를 보인다.
  - "하위 포함"을 켜면 모든 프로젝트를 보인다(NN과 같은 규칙).
- **폴더 줄**: 이름, 개수 "이 폴더 · 하위"(볼트 줄과 같은 표기), 펼치기.
- **폴더 다루기**
  - 만들기: 섹션 머리 `+`, 우클릭 "새 하위 폴더".
  - 이름 바꾸기: F2, 더블클릭.
  - 옮기기·중첩: 끌어 놓기(기존 분수 순서 재사용).
  - 색·아이콘: 우클릭, NN처럼. 단계 색 팔레트 + `#rrggbb`. 아이콘은 앱의 아이콘 몇 가지.
- **폴더 지우기**
  - 빈 폴더는 바로 지운다.
  - 내용이 있으면 둘 중 하나를 고른다(데이터를 잃지 않게).
    - "폴더만 지우기": 안의 프로젝트·하위 폴더는 위 폴더로 옮긴다.
    - "보관": 안의 것과 함께.
  - 게이트웨이에 `DELETE /api/folders/:id`(내용은 위로)를 더한다.
- **끌어 놓기**
  - 목록 칸의 프로젝트(여럿)를 폴더에 놓으면 그 폴더로 옮긴다.
  - "프로젝트" 줄에 놓으면 폴더 밖으로 옮긴다.
  - 바로가기 섹션에 놓으면 바로가기에 더한다.

### 2.3 탐색 칸: 바로가기 · 태그 · 보기 · 볼트

- **바로가기**
  - 무엇이든 넣는다: 프로젝트·폴더·태그·저장된 보기(볼트 노트는 이미 볼트의 "고정 노트"가 있으므로 넣지 않음).
  - 이름표만 바꾸고(원래 이름은 그대로), 끌어서 순서를 바꾸고, 가리키면 ✕로 뺀다.
  - 지금의 "고정" 칸을 대신한다. 처음 한 번, 고정된 작업들을 바로가기로 옮겨 담는다(`pinned`는 그대로 둠).
- **고정(목록 맨 위)**: `Work.pinned`.
  - 그 프로젝트가 들어 있는 모든 목록의 맨 위 "고정" 묶음에 온다.
  - NN은 폴더마다 고정이지만, 우리 프로젝트는 폴더 하나에만 있으므로 같은 뜻이다.
- **태그**
  - 프로젝트 노트의 태그(요약의 `tags`)를 `/`로 나눈 트리로 보이고 개수를 단다.
  - "태그 없음" 줄도 둔다.
  - 고르면 목록 칸에 그 태그(와 하위 태그)의 프로젝트가 나온다.
- **보기(기존 PKM 보기)와 볼트**: 지금 그대로.

### 2.4 목록 칸

- **머리**
  - 고른 것의 이름 · 개수.
  - `+`(그 폴더에 새 프로젝트 = 기존 `newSession({folderId})`).
  - "하위 포함"(NN의 Notes from subfolders).
  - 정렬 ⇅, 촘촘히/표준.
- **거르기 칸**: `project-query.ts` 문법. 머리의 돋보기로 열고 닫는다.
- **줄(표준)**
  - 이름, 단계 날인(단계 색), 미리보기(`preview`, 없으면 마지막 요청 첫 줄, 0~3줄 설정).
  - 날짜(정렬 기준의 날짜), 태그 칩, 세션 수·확인 필요 표시·일하는 중 점.
  - 하위 포함·태그 목록에서는 폴더 이름도 단다.
- **촘촘히**: 이름 · 단계 · 날짜 한 줄.
- **정렬**
  - 기준: 최근 활동(기본) · 만든 날 · 이름 · 마감일(속성) · 단계. 오름/내림.
  - 전역 기본 + 폴더마다 따로(NN과 같음).
- **묶음 머리**
  - 날짜 정렬이면 오늘·어제·이번 주·지난 주·이번 달·더 이전.
  - 하위 포함이면 "폴더별"과 "날짜별" 중 고른다(NN의 Group by folder/date).
  - "고정"은 늘 맨 위다.
- **고르기**: 클릭은 열기(기존 `openProject` 규칙). Ctrl/Shift+클릭은 여럿 고르기.
- **여럿을 고른 뒤 할 수 있는 것**
  - 끌어서 폴더로 옮기기.
  - 우클릭: 폴더로 옮기기…, 바로가기에 더하기, 고정, 단계 ▸, 태그 더하기…, 보관.
- **펼치기 ▸**: 그 프로젝트의 세션·문서(지금 트리의 줄을 그대로). 세션을 왼쪽에서 탐색하는 일은 여기서 한다.
- **키보드**
  - 목록에서는 ↑↓, Enter.
  - ←→로 칸 사이를 옮긴다. F2 이름, Delete 보관.
  - "내비게이터로" 단축키(기본 Ctrl+Shift+E, NN과 같음, ⋯ › 단축키에서 바꿈)로 목록 칸에 초점(사이드바가 숨었으면 연다).
- **양**: 프로젝트 300개에서도 부드럽게. 필요하면 보이는 줄만 그린다.

### 2.5 설정(이 기기 prefs)

- `navigator`: `{ layout: "dual" | "stacked" | "tree", navWidth, listWidth, selected, sortDefault, sortByFolder, includeSub, density, previewLines, groupSub: "folder" | "date", sections: {접힘} }`.
- `navShortcuts`: `{ kind: "work" | "folder" | "tag" | "view"; id; label? }[]`.
  - 키 이름 `shortcuts`는 이미 키보드 단축키가 쓰므로 쓰지 않는다.

## 3. 홈 = 보기 (Bases·노션식 묶기, 갈래 `feat/views`)

### 3.1 보기

- 홈의 네 모드(지금·프로젝트·흐름·문서)마다 머리에 **보기 탭**이 있다(Bases의 보기 목록처럼).
- 보기는 다음으로 이루어진다.
  - 모양: 보드·표·카드·목록, 프로젝트는 그래프도, 흐름은 달력.
  - 거르기(공용 문법), 정렬, **묶기**와 **하위 묶기**, 보일 속성, 묶음 모양.
- 막대의 단추: `묶기 ▾` `하위 묶기 ▾` `정렬 ▾` `거르기` `속성 ▾` `모양 ▾`. 대화상자가 아니라 작은 팝오버이고, 바꾸면 바로 그 보기에 저장된다(노션처럼).
- 탭 우클릭: 이름 바꾸기 · 복제 · 지우기 · 기본값으로. `+ 보기`.

### 3.2 묶기 키

| 키 | 묶음 | 순서·색 기본 |
|---|---|---|
| 단계 | 단계마다 | 단계 순서·단계 색 |
| 폴더 | 프로젝트 폴더마다(경로) | 트리 순서·폴더 색 |
| 태그 | 태그마다. 여러 값이면 각 묶음에 나온다(노션의 다중 선택) | 이름순 |
| 날짜 속성(마감일 등) | 기간: 지남·오늘·내일·이번 주·다음 주·이번 달·다음 달·나중·없음. 또는 월별·주별 | 시간 순 |
| 최근 활동·만든 날 | 오늘·어제·이번 주·지난 주·이번 달·더 이전 | 시간 순 |
| 목록·태그·링크 속성 | 값마다(여러 값이면 각 묶음) | 이름순 |
| 글·숫자·체크 속성 | 값마다(체크는 예/아니오) | 이름·숫자 순 |
| 엔진 | Claude·Codex·둘 다 | 엔진 색 |
| 상태(지금 모드) | 확인 필요·일하는 중·멈춤·조용함 | 지금의 순서 |

- 값 앞의 이모지 색을 기본 색으로 읽는다: 🟢 초록, 🔵 파랑, 🟣 보라, 🟠 주황, 🔴 빨강, 🟡 노랑, ⬜ 회색.
  - 그래서 볼트 DIKM 값(🟢 D · 🔵 I · 🟣 K · 🟠 M · ⬜ 보류)이 바로 그 색으로 묶인다(지식체계별).
- "값 없음" 묶음은 맨 끝에 둔다. 빈 묶음 숨기기는 보기 설정이다.
- 하위 묶기를 쓰면 이렇게 보인다.
  - 보드: 열은 묶기, 가로줄(스윔레인)은 하위 묶기. 예: 마감 기간 열 × 중요도 줄.
  - 표·목록·카드: 묶음 머리 안에 하위 묶음 머리.

### 3.3 묶음의 모양 (Bases Look처럼)

- **묶음 색**: 묶음 머리를 우클릭하거나 `모양 ▾`에서 값마다 색을 고른다(팔레트 + `#rrggbb`). 보기에 저장된다.
- **테두리**: 묶음 구역을 그 색으로 두른다. 보드 열은 위에 굵은 띠를 단다.
- **옅은 바탕**: 묶음 구역과 열을 그 색의 옅은 바탕으로 채운다. 세기는 0~30%.
- **머리 강조**: 묶음 머리를 크고 굵게, 묶음 색으로 쓴다.
- **개수·접기**: 묶음 머리를 누르면 접히고, 보기에 기억된다.
- 디자인 원칙("괘선 노트")을 지킨다.
  - 깊이는 괘선과 면이다. 흐린 그림자는 쓰지 않는다(그래프 패널의 교훈: 움직이는 것 위의 흐림은 WebKitGTK에서 매 프레임 비싸다).

### 3.4 끌어 놓기로 값 바꾸기

- 보드에서 카드를 다른 열이나 줄로 옮기면 묶기 키의 값이 바뀐다.
  - 단계: 지금 칸반처럼 되돌리기 알림과 함께.
  - 폴더: 옮기기.
  - 값 하나인 글·목록 속성: 그 값으로 쓴다.
- 날짜 기간, 태그(여러 값), 엔진, 상태는 끌 수 없고 끌면 까닭을 알린다.

### 3.5 모드마다 기본 보기 (처음부터 있음, 지울 수 있음)

- **프로젝트**
  - 지금 화면은 그대로 기본 보기가 된다: 카드, 표, 칸반 = "단계"(보드), 그래프.
  - 새 기본 보기: "마감 × 중요도"(보드: 마감일 기간 × 중요도), "폴더별"(표).
  - 기본 속성 템플릿에 `중요도`(글, 안내 "높음 · 보통 · 낮음")를 더한다.
  - 글 속성 칸에 다른 프로젝트들이 쓴 값을 제안한다(노션의 선택처럼 고르게).
- **지금**: 지금의 묶음(확인 필요·일하는 중…)이 기본 보기다. 묶기를 폴더·프로젝트·엔진으로 바꿀 수 있다.
- **문서**: 지금 화면이 기본 보기다. 묶기는 프로젝트·폴더·형식·수정 기간.
- **흐름**: 달력(하루·주·달)은 그대로 두고 두 가지만 더한다.
  - "거르기": 폴더·태그·단계·속성.
  - "색 기준": 엔진(지금처럼)이나 단계·폴더·아무 속성. 묶음 색을 블록에 칠한다.
