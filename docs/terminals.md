# 작업공간 터미널

작업공간 선택기의 **터미널…**에서 새 셸을 열거나 이전 터미널을 다시 연다. 기본 셸 또는 실행 파일과 인자를 직접 지정한다. 현재 작업공간의 실제 폴더에서 실행하며, 일반 탭과 같은 이동·분할·배치 복원 규칙을 쓴다. 터미널에서 분할하면 같은 폴더에 별도 셸을 연다.

탭 닫기는 실행 종료와 구분한다. 닫힌 탭은 목록에서 같은 실행으로 다시 연다. **실행 종료**와 확인을 거치면 앱이 소유한 셸을 종료하고 출력은 보존한다. 앱 정상 종료 때도 소유한 실행을 닫는다. 실행 중인 터미널은 같은 물리 폴더를 가리키는 다른 프로젝트에서도 작업공간 보관·제거를 막는다.

출력 검색·정규식·대소문자, 선택 복사, 붙여넣기와 스크롤 위치를 지원한다. 원시 출력은 터미널마다 최근 2 MiB와 마지막 청크 경계까지 저장한다. 앞부분이 잘렸으면 안내한다. 재시작 시 출력과 상태를 복원하며 저장된 PID나 명령을 자동으로 실행하지 않는다. 이전 앱 실행 중 끊긴 기록은 중단 상태가 된다. 모든 TUI의 화면·중간 크기 변경을 완전히 재현하는 기록은 아니다.

Rust 실행파일의 `--pty-worker`가 `portable-pty`로 PTY를 열고, 인증된 로컬 gateway가 상속 파이프로 제어한다. 별도 터미널 서버나 Electron/node-pty는 없다. 키 입력 요청은 순서를 유지하며 출력 바이트와 커서 위치를 한 DB 트랜잭션으로 기록한다. 한 gateway에서 동시에 16개까지 실행한다.

## 검증 범위

- 실제 PTY의 cwd·한글·크기·Ctrl-C·종료 코드·같은 폴더 보호·3.3 MB 출력 제한·재시작 기록을 호스트에서 검사했다. 최종 호스트/탭/하네스 회귀 12/12, 앞선 연관 회귀 40/40과 전체 타입·빌드가 통과했다.
- 실제 Linux Tauri 12/12: 사람이 보내는 키 입력으로 파일 생성, 출력 검색, 다른 PID의 분할과 크기 변경, 탭 닫기/재열기, 명시적 종료, 새 포트 재시작의 전체 출력 복원과 자동 재실행 금지. 최종 화면도 확인했다.
- Windows ConPTY·macOS, IME·고급 TUI·분리된 자식 프로세스의 모든 종료 경우는 후속 검증이다. OSC52·링크·테마 가져오기·빠른 명령·부동 터미널 등 전체 Orca 터미널 동등성은 아직 완료가 아니다.
