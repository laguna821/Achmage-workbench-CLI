- 시작 기준: 로컬 `b3bceab5`, 공개 v0.2.2 `0cfc9443`
- 구현 브랜치: `feat/unified-workbench-v0.3`

## 검증·릴리스 순서

1. 변경한 계약과 데이터 보존 동작을 국소 테스트로 확인한다.
2. 연결된 웹/호스트/편집기 타입 검사와 회귀 검사를 수행한다.
3. 실제 Linux 앱에서 창·입력·문서·세션·종료/복구를 확인한다.
4. 준비된 변경을 한 묶음으로 GitHub에 올리고 OS별 빌드/설치 검사를 수행한다. 같은 실패를 수정 근거 없이 반복 push하지 않는다.
5. Windows NSIS/MSI, macOS Apple silicon DMG, Linux AppImage/deb/Arch 패키지의 결과·해시·용량을 확인하고 릴리스 노트에 검증 범위를 명시한다.
6. 기능/설치 검증이 끝난 버전만 공개 릴리스로 게시한다.

## 시작 환경

GitHub 저장소 쓰기 권한과 기존 릴리스 워크플로를 확인했다. 로컬 Node 26.8.1, npm 12.2.0, Rust/Cargo 1.99.1이 있다. Rust는 기본 PATH에 없지만 기존 `~/.cargo/bin` 설치를 사용한다. CI는 현재 Node 24다. 차이는 실행 결과에 기록한다.

현 장치의 Achmage resourceManagement는 비활성이다. 이를 임의로 활성화하거나 자원 정책을 우회하지 않는다. 무거운 작업은 동시에 여러 개 실행하지 않고 현재 자원 상태를 확인한다. 향후 활성 상태라면 예약과 stable resource-run을 사용한다.

기존 다른 작업트리와 미커밋 E2E 파일은 보존한다. 이전 Broadway 실패를 같은 조건으로 재시도하지 않는다. 실행 파일 인자와 display/socket 조건을 수정·기록한 뒤 새 검증을 한다.

## 작업별 결과

- Git 검토/적용에서 인덱스를 수정하지 않도록 변경했다. NUL 경로 파싱, 빈 파일/바이너리 패치, 삭제 실패 전파, 미병합 커밋 브랜치 보존, stale worktree 식별 거부를 추가했다. 임시 Git 저장소 회귀 10개 통과.
- 저장된 모델 ID가 현재 목록에 없어도 그대로 표시한다. 요청 별칭과 실제 모델명을 구분하며 엔진 기본값으로 돌아가는 선택을 명시했다. Claude 모델 캐시는 계정/엔진 버전별로 분리하고 기존 무범위 캐시는 다시 읽는다. 모델 관련 6개 회귀 통과.
- 실제 앱 검사 하네스를 복구했다. 미구현 검사를 성공 처리하지 않고, 검증된 실행파일·임시 데이터·대역 엔진·전용 Broadway/D-Bus로 실행한다. Linux 추상 소켓 readiness와 설정 저장 debounce에 맞게 검사를 수정했다.
- `npm run typecheck`, `npm run build`, Tauri `build --debug --no-bundle` 통과. 실제 Linux Tauri 창 시작/첫 화면/온보딩/저장 검사 4개 통과 및 정상 종료. 이 결과는 최신 Office 전체 기능이나 OS별 설치본 검증을 의미하지 않는다.
- 2026-10-30: 재귀 좌우·상하 분할(최대 16칸), 칸 이동/교환, 키보드·포인터 경계 조절, 좁은 창의 선택 칸 표시, gateway 설정 기반 배치·초점·비율 복원을 구현했다. 새 칸 입력 초안은 분리하고 새 요청은 시작한 칸으로 돌아간다.
- 분할 관련 단위/컴포넌트/인자 회귀 16개 통과. 실제 Linux 앱의 시작 4개 + 2×2 생성·드래그·DOM 보존·키보드·좁은 창·새 포트 재시작·닫기 등 총 12개 통과. 화면을 검토해 입력창 높이 문제도 수정했다. Workspace별 탭/스크롤/커서 복원 및 다른 OS는 아직 검증하지 않았다.
- 다음: 작업공간별 탭·상태 복원. 릴리스는 아직 게시하지 않았다.
- 폴더 노트 템플릿: 상위 분류 상속, 하위 재정의/해제, 본문만 있는 템플릿, MD 파일 가져오기, 새 노트 초기화. 기존 노트는 템플릿 변경이나 분류 이동으로 덮어쓰지 않는다. 원문 줄바꿈·콜론 속성명·목록 형태를 보존한다.
- 프로젝트 썸네일: `thumbnail`/`cover`/`썸네일`/`표지` 속성 또는 첫 이미지. 카드·보드·표·목록의 표시 필드와 내비게이터에 연결했다. 이미지는 보이는 범위에서 읽고, 로컬 파일은 인증된 경로로 표시한다. 보관함 숨김 설정을 이미지 인덱스와 직접 요청에도 적용했다.
- PKM 회귀 46개, 호스트/웹 타입 검사 및 빌드 통과. 실제 Linux 앱 시작+템플릿 저장→상속 노트 생성→썸네일→원문 보존 검사 9개 통과. WebKitWebDriver는 일괄 `sendKeys`에서 LF/비BMP 문자를 누락하므로 native 시나리오는 줄별 입력과 실제 Enter를 사용한다. CRLF/이모지 원문 보존은 파일 회귀에서 별도로 확인했다.
- `.base` 교환: 표·카드·목록·칸반, 자료형을 유지한 노트/파일 속성 필터, 미리보기, 설정 복원, 새 파일 내보내기. 지원하지 않는 수식이나 조건은 보기별로 거절하고 원본 `.base`/Markdown을 수정하지 않는다. [지원 범위와 제한](bases-interoperability.md)을 별도로 기록했다.
- Bases와 기존 PKM 회귀 79개 통과 후 복합 필터 왕복 저장 회귀를 추가했다. YAML 자동 별칭 때문에 재가져오기가 실패하는 문제를 수정해 교환 회귀 6개 통과. 실제 Linux 앱 14개 검사에는 내보낸 파일 재가져오기도 포함한다. OS 저장 대화상자 조작과 Windows/macOS는 G6 대상이다.
- `yaml` 2.9.1을 추가하고 기존 간접 의존성 `body-parser` 2.4.0, `fast-uri` 3.1.9로 보안 패치했다. 전체/production npm audit 모두 취약점 0개. 호스트/웹 타입 검사, 웹·호스트·Tauri 빌드 통과.
- [Workspace 계약](workspaces.md): 별도 테이블·ID, 기존 ID/리비전/원문을 보존하는 트랜잭션 이행, 구버전이 나중에 쓴 행 복구, 일반 폴더 연결, 같은 worktree의 복수 세션, 보관/실제 제거 구분을 구현했다. UI에서 연결·이름 변경·보관/복원·공간 전환이 가능하다.
- 격리 사본 실행에서도 문서 예약/스캔이 원래 폴더를 쓰던 경로 문제를 수정했다. 작업 사본·상대 파일 경로·세션 내보내기·그림 생성용 세션/저장도 해당 Workspace를 사용한다. 대화 가져오기는 이미 연결한 공간을 재사용한다.
- Workspace/Git/문서/세션/갈래 30개, 별도 기존 회귀 66개, 그림/가져오기 19개 통과. 추가한 구버전행 복구를 포함해 Workspace 단독 5개 통과. 호스트/웹 타입 검사와 빌드 통과. 같은 임시 프로필에서 실제 앱 시작→분할/재시작→PKM/Bases→Workspace 전체 26개 통과.
- 연속 native 검사에서 PKM의 `paneLayout:null`이 이전 세 칸을 초기화하지 않아 클릭이 실패했다(20/21). 시작 배치를 명시적 한 칸으로 고치고 같은 제품 빌드로 26/26 통과했다. 실패 스크린샷/stack 저장도 추가했다. 전체 탭·스크롤·커서 및 OS 설치본 복원은 후속이다.

- 문서 저장 실패를 무시하고 이동하던 경로를 수정했다. Office는 저장 확인 없이 4초 후 닫히지 않으며, 무응답·충돌을 저장 성공으로 보지 않는다. 연속 클릭은 마지막 목적지만 열고 프로젝트/세션/문서 식별자를 함께 전환한다. 텍스트 저장 중 추가 입력이 있으면 이동을 보류한다.
- 관련 단위/컴포넌트/인자 8개, 웹 타입 검사·빌드·Tauri 빌드와 실제 앱 8개 검사 통과. 실제 파일 충돌에서 프로젝트 이동/탭 닫기 보류, 편집 내용과 외부 디스크 내용 보존, 해결 후 저장·이동을 확인했다. Workspace별 탭 모델은 후속이다.

### 공통 탭·배치 구현 결과

- [공통 탭과 배치](workspace-layouts.md): 고정 탭 ID, 그룹별 순서/활성/MRU, 드래그·키보드 순서 변경·닫기, 방문한 편집기의 DOM 유지, Workspace별 독립 배치와 전체 혼합 배치를 구현했다. 닫거나 이동해도 실제 파일과 세션은 유지한다.
- 배치를 전역 설정의 64 KB 한계와 분리해 Workspace별 최대 512 KB record에 저장한다. 판 번호 CAS 충돌 시 자동 덮어쓰기를 멈추고 원격 불러오기/현재 배치 저장을 명시적으로 선택한다. 이전 설정 원문은 DB에 보존한다.
- Markdown/텍스트의 커서·스크롤·보기 모드/읽기 위치, 대화 스크롤과 답변 따라가기를 저장한다. 빠른 탭 전환 시 debounce가 숨김 상태를 보고 위치를 버리던 문제를 이벤트 시점 캡처로 수정했다. 재시작 위치 검사 18/18 통과.
- 오른쪽 클릭 후 WebKit이 Pointer 이벤트 없이 mouse 이벤트만 보내는 경우도 드래그가 동작하게 했다. 한 press가 두 이벤트 계열을 소유해 중복 drop을 막는다. 실제 앱 시작→분할→PKM/Bases→Workspace→문서 전환→탭/재시작/CAS 연속 40/40 및 웹·관련 호스트 회귀 235/235 통과.
- 프로젝트 노트 본문은 편집 시작 판과 실제 디스크 해시를 함께 확인한다. 외부 수정·삭제를 덮지 않고, 저장 실패 시 편집창과 초안을 남긴다. 페이지 갱신으로 편집 시작 판을 바꾸지 않는다. 추가 호스트 회귀 43/43, 실제 앱 문서/프로젝트 노트 전환 검사 12/12 통과. 호스트/웹 타입 검사와 웹·호스트·Tauri debug 빌드 통과.
- Office iframe DOM 유지 컴포넌트 검사는 내부 페이지/셀/객체 상태의 native 검증을 뜻하지 않는다. Office 내부 위치, PKM 목록 스크롤, 향후 배치 형식의 무변이 처리와 OS별 설치 검증은 후속이다. 다음은 공통 문서 레지스트리·세션/참조·템플릿 연결이며 릴리스는 아직 게시하지 않았다.
