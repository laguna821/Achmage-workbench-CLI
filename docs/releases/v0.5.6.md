# 0.5.6 — Gemini 엔진, 다른 대화 읽기, 휴대폰에서 만들고 열기, 작업 폴더와 끌어놓기

Claude Code와 Codex에 더해 Gemini를 셋째 엔진으로 쓸 수 있습니다. 같은 프로젝트의 AI들이 서로의 대화를 읽고 이어서 일하고, 휴대폰(테일스케일)에서도 프로젝트와 문서를 만들고 열 수 있습니다. 쓰시던 프로젝트와 대화, 문서, 설정은 그대로 이어집니다. 0.5.2부터 0.5.5까지를 쓰고 계시다면 설정 › 정보 › 업데이트에서 올릴 수 있습니다.

## Gemini

- **셋째 엔진:** Google의 공식 Antigravity CLI를 이 컴퓨터에 설치하고 그 CLI로 로그인하면, Gemini와 새 대화를 열 수 있습니다. 대화 화면, 승인 카드, 파일 카드(누르면 문서 탭으로 열림), 중단, 다시 열면 이어 하기, 그림 첨부, 프로젝트와 휴대폰·메신저까지 Claude·Codex와 같은 방식으로 씁니다. 모델과 생각 수준은 Antigravity가 주는 목록에서 고릅니다.
- **설정 › AI 엔진 › Gemini:** Antigravity CLI가 없으면 **Antigravity CLI 설치**가 Google의 설치 명령을 Workbench 터미널 탭에서 실행합니다. **Gemini 로그인**도 터미널 탭에서 Antigravity가 직접 로그인합니다. Workbench는 로그인 주소나 코드를 읽지 않습니다. Antigravity CLI는 1.5.2 이상이 필요하고 1.5.12 이상을 권합니다.
- **구독 로그인만 씁니다:** Google 계정(개인·회사)으로 Antigravity에 로그인한 구독으로 돕니다. API 키는 쓰지 않으며, 이 컴퓨터에 API 키나 Google Cloud 설정이 있어도 Antigravity에 넘기지 않습니다.
- **처음 켤 때 동의:** Google의 Antigravity 약관은 아직 다른 앱에서 쓰는 것을 막는 문장을 담고 있습니다. Google DeepMind 직원들이 이런 방식의 앱은 괜찮다며 약관을 고쳐 보겠다고 밝혔지만 공식 약관과 FAQ는 아직 바뀌지 않았습니다. 그래서 위험을 알리는 안내와 Google FAQ·약관 링크를 보여 주고, **위 내용을 읽었고 내 Google 계정으로 씁니다**를 켠 뒤에만 Antigravity를 띄웁니다.
- **Google이 문제 삼을 일을 하지 않도록:** 사용자가 설치한 Antigravity를 고치지 않고 그대로 쓰고, Workbench라는 이름을 그대로 밝히고, 로그인 정보에 손대지 않습니다. 승인은 ‘묻기’와 ‘자동(파일 고치기만 허락)’만 있고 전체 접근과 ‘항상 허용’은 없습니다. 사람이 보낸 요청에만 쓰고, 예약 작업, 자동 실행 API, 다른 AI가 대신 넘기는 일에는 쓰지 않습니다(메신저에서 직접 보내는 것은 됩니다). Gemini에는 요청과 꼭 필요한 정보만 보냅니다.
- **Google이 계정을 막으면** 대화와 설정에 “Google이 이 계정의 Antigravity 사용을 막았습니다.”라고 알리고 다시 보내지 않습니다.
- **Gemini에서 아직 안 되는 것:** 이 요청 전으로 되돌리기, 지금 압축, 하위 작업 목록, 사용 한도 막대(대화에 `/usage`를 보내면 Antigravity가 알려 줍니다), 그림 만들기(프로젝트의 Codex 그림 대화로 넘깁니다), 문서 탭 옆의 문서 AI.

## 다른 대화 읽기

- 같은 프로젝트에서 “방금 Codex에서 한 작업 보고 이어서 해 줘”처럼 말하면, AI가 그 프로젝트의 다른 대화(Claude·Codex·Gemini·문서 AI)를 찾아 최근 요청과 답, 바뀐 파일을 읽고 이어서 일합니다. 실행 상세에는 “「서론 고치기」 대화를 읽었습니다 · 최근 2개”처럼 남습니다.
- 다른 프로젝트의 대화는 읽지 않습니다. 비밀 값은 가리고, 읽은 내용은 지시가 아닌 자료로만 씁니다. 따로 켤 설정은 없습니다.

## 휴대폰(테일스케일)

- **새 프로젝트·새 문서:** ⋯ › 새로 만들기에서 새 프로젝트와 새 문서(한글 문서 포함)를 만들고 바로 엽니다.
- **문서 열기:** 한글·워드·파워포인트·PDF는 쪽 그림으로, 마크다운·엑셀 등은 글로 보입니다. 대화의 파일 카드, 요청에 붙은 문서, 답 속 파일 링크에서도 열립니다. 휴대폰에서는 문서를 읽기만 합니다.
- **휴대폰에서 이제 되는 것:** 파일 올리기(25MB까지), 새 폴더, 프로젝트 이름·보관·고정·폴더로 옮기기·단계·속성, 문서 이름 바꾸기와 목록에서 빼기, Markdown 변환과 한글로 내보내기, 대화를 Markdown으로 저장.
- **휴대폰에서는 PC에서 하라고 알려 주는 것:** 파일·프로젝트 지우기, PDF 쪽 돌리기·지우기, 문서 AI, 볼트, 작업 폴더 바꾸기.
- 대화를 처음 열 때 한 번 내려야 보이던 문제와, 휴대폰에서 오류 알림이 잘리던 문제를 고쳤습니다.

## 목록과 대화창

- **폴더:** `>`로 접으면 안의 프로젝트가 모두 가려지고(지금 열린 프로젝트도), 접힌 폴더 줄에 확인할 것의 개수가 보입니다. 폴더 안에 새 프로젝트를 만들거나 옮겨 넣으면 그 폴더가 펼쳐지고 새 줄이 보입니다.
- **이름 바꾸기:** 메신저 자리(‘텔레그램 대화’, ‘Slack 대화’)의 이름을 바꿀 수 있고, 봇의 메뉴에도 바꾼 이름이 나옵니다. 프로젝트·폴더 줄을 두 번 누르면 이름을 바꾸고, 이름을 비우면 자동 이름으로 돌아갑니다.
- **첨부 › 작업 폴더:** 첨부 메뉴 맨 위에 이 대화의 작업 폴더가 보이고 **작업 폴더 바꾸기…**로 바꿉니다. 아직 시작하지 않은 대화는 그 폴더로 옮기고, 시작한 대화는 그대로 두고 고른 폴더에서 새 대화를 엽니다. 파일은 그 아래 **파일 첨부…**로 넣습니다.
- **끌어놓기:** 대화창 어디에 파일을 끌어 와도 “여기에 놓으면 첨부합니다”가 뜨고, 놓으면 첨부됩니다(Linux 파일 관리자가 넘기는 주소 목록도 받습니다).
- **엔진 로그인:** 설정 › AI 엔진에서 Claude·Codex 모두 로그인 / 다른 계정으로 다시 로그인 / 로그아웃 / 로그인 상태 확인을 쓸 수 있습니다.
- **디자인 편집기 출처 표시:** 앱을 켤 때마다 메인 화면 아래에 나오던 줄을 없애고, 디자인 탭을 열 때 그 편집기 위쪽에 보이게 옮겼습니다.

## 보안

- **엔진 도구의 파일 교환:** Workbench가 엔진에게 주는 도구들(찾기, 데스크톱, 메신저 리모컨, 비밀 값 입력, 웹 브라우저 도구 등)이 엔진과 파일로 주고받는 방식에 구멍이 있었습니다. 격리 모드로 도는 엔진이 사용자의 다른 파일을 덮어쓰게 하거나 게이트웨이를 멈추게 할 수 있었고, 이전의 모든 0.5 판에 있었습니다. 하나의 안전한 방식으로 바꿨습니다.
- **휴대폰:** 연결된 휴대폰이 프로젝트 밖의 파일을 읽거나 이름을 바꿀 수 있던 길, 형식을 숨긴 요청, 끝없는 프로젝트·파일 만들기를 막았습니다.

## 앱 안에서 업데이트

설정 › 정보 › 업데이트에서 새 판으로 올릴 수 있습니다. 단추가 듣지 않으면 전처럼 설치 파일을 받아 설치하면 됩니다.

- Windows 설치 파일(.exe), macOS(.dmg), Linux AppImage, Linux 사용자 폴더 설치: 그 자리에서 바꾸고 다시 엽니다.
- Windows MSI, Linux .deb, Arch(pacman): 이번 판에서도 제자리 설치를 하지 않습니다. ‘내려받기’를 누르면 확인을 마친 설치 파일을 ‘다운로드’에 받아 두고 할 일을 한 문장으로 알려 줍니다.

## 설치

아래 설치 파일 가운데 내 컴퓨터에 맞는 것 하나를 받으세요. 이미 쓰고 계시다면 앱을 지우지 말고 새 판을 그대로 설치하면 됩니다. 프로젝트, 대화, 문서, 설정, 메신저 연결은 그대로 남고, 저장 형식을 바꿔야 할 때는 바꾸기 전에 복구본을 먼저 만듭니다.

- **Windows:** `-setup.exe`로 끝나는 파일(또는 `.msi` 파일)을 실행합니다. 설정에서 바로 업데이트하려면 `-setup.exe`를 쓰세요.
- **macOS:** `.dmg` 파일을 열고 앱을 응용 프로그램 폴더로 옮겨 예전 앱을 바꿉니다. 업데이트한 뒤 키체인이 허락을 물으면 ‘항상 허용’을 누르세요.
- **Linux:** `.AppImage` 파일이나 `.deb` 파일을 씁니다. Arch Linux와 CachyOS는 `.pkg.tar.zst` 파일을 씁니다.

AI가 하던 일이 있으면 그 일이 끝난 뒤에 설치하세요.

## 알려진 한계

**이번 판에서 새로 생긴 것**

- **Gemini는 진짜 Antigravity CLI로 시험하지 못했습니다.** Antigravity와 같은 방식으로 말하는 시험용 프로그램으로만 확인했습니다. 실제 설치, 로그인, 대화, 진행 중 방향 바꾸기, 계정이 막혔을 때의 문구, ‘묻기’ 모드에서 파일마다 묻는지(볼트 보호가 여기에 기대고 있습니다)는 사람이 아직 확인하지 않았습니다. Windows·macOS에서 Antigravity를 찾는 위치도 문서로만 확인했습니다.
- Gemini의 계정 위험은 낮게 설계했지만 없지는 않습니다. Google이 약관을 고치기 전까지는 처음 켤 때의 안내를 읽고 정하세요.
- 다른 대화 읽기는 시험용 엔진으로 확인했습니다. 실제 Claude·Codex·Gemini가 언제 이 도구를 꺼내 쓰는지는 요청하는 말에 따라 다를 수 있습니다. 잘 안 되면 “같은 프로젝트의 Codex 대화를 읽고”처럼 분명히 말해 주세요.
- 파일 끌어놓기는 시험용 브라우저에서 확인했습니다. 실제 앱 창에 실제 파일 관리자에서 끌어놓는 것은 사람이 아직 확인하지 않았습니다.
- 휴대폰 기능은 실제 휴대폰과 실제 테일스케일로 확인하지 않았습니다. 휴대폰에서 대화를 띄워 두어도 PC의 완료 소리는 그대로 울립니다.
- 로그아웃한 뒤 진행 중이던 그 엔진의 대화는 중간에 멈출 수 있습니다. 답이 끝난 뒤에 로그아웃하세요.
- Antigravity CLI에는 로그아웃 명령이 없어 Gemini 칸에는 로그아웃 단추가 없습니다.

**0.5.5에서 이어지는 것**

- 한글 프로그램이 없는 환경에서 만들었습니다. 변환하거나 내보낸 한글 문서는 Workbench의 한글 엔진으로 다시 읽어 확인했을 뿐입니다. 중요한 문서는 한글에서 한 번 열어 확인하세요.
- PDF 불러오기(PDF → Markdown), PDF 첨부 파일 추가·다른 문서와 비교, 파워포인트 JPG 내보내기, 엑셀 `.ods` 저장, 한글 탭의 고급 인쇄 결과 미리 보기와 인쇄는 아직 없습니다.
- Google Drive는 이전 방식 그대로입니다.
- 편집기 함께 쓰기와 가벼운 대화 화면, 테일스케일과 슬랙은 자동 시험과 견본 프로그램으로 확인했습니다.

**보안과 설치**

- 전체 접근으로 일하는 AI(휴대폰 대화 포함)는 Windows와 Linux에서 이 컴퓨터의 비밀번호 저장소를 읽을 수 있습니다(macOS는 키체인이 먼저 허락을 묻습니다). 카드나 주거래 은행 로그인은 암호로 여는 보관함이 나올 때까지 넣지 마세요.
- Windows와 macOS 설치본은 자동으로 만들고 설치하고 처음 실행까지 확인했지만, 아직 사람이 실제 컴퓨터에서 써 보지는 않았습니다. 이상한 점이 보이면 알려 주세요.
- macOS 판은 개발자 인증서로 서명되지 않아서, 처음 열 때와 업데이트할 때마다 확인 창과 키체인 허락을 물을 수 있습니다. ‘항상 허용’을 누르세요.

**휴대폰 메신저**

- 슬랙에서는 앱이 내 메시지를 지울 수 없습니다. 비밀 값은 채팅에 적지 말고 [비밀 값 입력] 창에 넣으세요. 인증번호를 잘못 보냈다면 직접 지워 주세요.
- 인증번호나 링크를 넣는 단계가 끝나지 않고 멈추면(취소, 시간 초과, 멈춰, 새 대화, 잠금, PC 다시 시작), 30분 동안 숫자 하나나 링크 하나만 있는 짧은 메시지(예: “2025 보고서 열어 줘”)가 대화에서 빠지고 지워질 수 있습니다. 쓴 그대로 보내려면 5분 안에 [그대로 보내기]를 누르세요. 5분이 지났거나 PC가 다시 시작됐다면 다시 써 주세요.
- 단계가 끝난 뒤에는 인증번호 메시지를 찍은 화면이나 글 없는 사진을 보내지 마세요. 그림은 확인할 수 없어서 그대로 AI에게 갑니다. 글을 붙인 사진은 확인합니다.
- 슬랙에서 PC 쪽 단계가 기다리는 동안에는, 그 단계를 마친 뒤 메시지를 “이어서”로 시작해 주세요. 그러지 않으면 최대 30분 동안 숫자가 든 짧은 메시지를 붙잡아 둡니다.
- 긴 문장 속에 ‘인증번호’나 ‘코드’ 같은 말 없이 적은 번호, 두 메시지로 나눠 보낸 번호, 서로 다른 링크가 두 개 든 메일은 단계가 끝난 뒤에는 알아보지 못합니다. 인증번호는 단계가 물을 때에만 보내세요.
- 비밀번호나 키는 입력 칸이 닫힌 뒤에는 알아볼 수 없습니다. 그 뒤에 대화에 절대 적지 마세요.
- 자동으로 채운 값은 그 직후 페이지를 다루는 AI가 읽을 수 있습니다(브라우저에 저장된 로그인 정보 포함).
- 8글자보다 짧은 값은 밖으로 나가는 파일에서 찾아내지 못합니다.
- 연도와 같은 네 자리 비밀번호를 쓰면, 그 단계가 진행되는 동안 페이지에서 그 연도도 가려집니다.
- PC 화면에서 채운 값은 사용 기록에 따로 남지 않습니다.
- 큰 Word 문서(.docx)를 보낼 때 잠깐 멈춘 듯 보일 수 있습니다.

**한글 문서**

중요한 문서는 마지막에 한글에서 한 번 열어 인쇄 모양을 확인하세요.

- 예전 한글로 저장한 일부 문서에서, 쪽 맨 위 제목 표 아래 내용이 한 줄(약 5.6 mm) 아래로 내려가 보이고 그 쪽에 한 줄이 덜 들어갈 수 있습니다. 내용이 사라지지는 않습니다.
- 자동 번호만 있는 줄이 한 줄 내려갈 수 있습니다.
- 종이에 고정된 ‘위아래 자리차지’ 상자가 있는 예전 문서는 쪽 나눔이 한글과 한 줄쯤 다를 수 있습니다.
- 드물게 쪽 끝 문단의 마지막 한 줄이 앞 쪽에 남거나, 내어쓰기한 줄 끝이 빈칸 하나만큼 어긋날 수 있습니다.
- 외톨이 줄 방지는 새로 입력한 문서에는 사실상 적용되지 않습니다.
- 한 구역에 쪽 번호 설정이 여러 개 있으면 하나로 합쳐 구역 첫 문단에 둡니다.
- 새 엔진에서는 시험 문서 1,513개 가운데 13개의 줄 배치가 0.5.4와 달라졌습니다(쪽 수가 바뀐 문서는 없습니다). 모두 이음오피스의 엔진과 같은 결과입니다.
- 암호가 걸린 한글 문서는 열어 볼 수 있지만 저장할 수는 없습니다. 고쳐야 한다면 한글에서 암호를 푼 뒤 여세요.

**그 밖에**

- 같은 문서를 두 칸에 나란히 열면 한쪽은 읽기만 됩니다.
- 이 컴퓨터 안에서 하는 음성 받아쓰기는 이번 판에서도 처음부터 끝까지 다시 시험하지 못했습니다. 잘 안 되면 알려 주세요.
