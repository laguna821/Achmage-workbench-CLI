# 0.3.1 — 생성 메뉴·요청 검색·볼트 탐색 수정

0.3.0 Windows 실사용 피드백에 대한 긴급 수정이다. Windows용 Lightpanda 자체 이식은 이번 범위에 포함하지 않는다.

- 탭의 `+ 만들기`, 프로젝트 목록의 `만들기`, 프로젝트 행의 `+`, 프로젝트 영역 우클릭에서 새 문서·doory 디자인·Claude/Codex 세션을 만들 수 있다. 문서 생성은 AI 요청을 보내지 않으며, 편집하던 프로젝트와 작업공간을 유지한다.
- Ctrl+K의 프로젝트별 첫 결과 묶음에 일치하는 **내 요청**을 포함한다. 프로젝트·세션·파일 제목 3개가 요청 원문을 밀어내던 경우를 재현하고 수정했다. 답변의 반복된 단어보다 같은 등급의 사용자 요청을 우선한다.
- `ppt로`, `K에서`, `AI와`, `PDF를` 및 짧은 영문 단어도 원문에서 찾는다. 기존 기록으로 검색 캐시를 한 번 복구하며, 이후 캐시 쓰기 실패도 다음 실행에서 다시 복구한다. 대화 원본과 문서 파일은 변경하지 않는다.
- 읽기 전용 볼트를 각 탭 안에서 탐색한다. 뒤로/앞으로, Alt+←/→, 마우스 뒤로/앞으로 버튼, 상위 폴더, 경로 클릭, 하위 폴더 이동 및 우클릭 이동 메뉴를 지원한다. 오른쪽 볼트를 탐색해도 왼쪽 채팅 탭은 유지된다.

## 검증

- TypeScript 전체 검사 통과.
- 앱 테스트 188개 파일, 1,290개 통과·6개 제외.
- 실제 화면 통합 검사 26/26 통과: 실제 입력 → Ctrl+K, 편집기 안에서 생성, doory 캔버스, 프로젝트 빈 공간 우클릭, 병렬 세션, 분할 볼트 경로/키보드/마우스 이동, 볼트 원문 보존.
- 사용자 제공 예시 `방금 이 앱을 새로 설치했는데 간단한 마크다운 문서를 하나 만들어봐 mermaid 그림이랑 테이블도 같이 포함해서`를 실제 입력한 뒤 `마크다운 문서`, `mermaid`, `테이블`, 전체 문장으로 검색 확인.
- Fast Find 원본 golden/typo-recall 통과. 로컬 release 코어 172개 중 기능 검사 171개 통과; 10k 문서 타이밍 검사 1개는 14.488ms로 로컬 10ms 기준 초과. 기존 CI는 원본의 공유 러너 허용치(50ms)를 사용한다. 기준이나 테스트 코드를 변경하지 않았다.
- Windows/macOS 설치 검증에 사용자 예시 프롬프트 및 영문+한글 조사 회귀 검사를 추가했다. 설치본의 실제 결과는 해당 릴리즈 Actions 실행을 기준으로 한다.

로컬 화면 검사는 새 웹/호스트/검색 실행기 및 공식 0.3.0의 변경 없는 오피스 렌더러를 사용했다. 배포 Actions는 전체 렌더러와 OS별 설치본을 다시 빌드한다.
