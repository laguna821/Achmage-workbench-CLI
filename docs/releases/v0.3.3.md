# 0.3.3 — 최신 모델·프로젝트 삭제·완료 알림·문서 AI 병렬 작업

- **Codex 최신 모델 목록**: 모델 선택기를 열 때 로그인한 엔진에서 목록을 다시 조회하고 모든 페이지를 읽습니다. 새로고침 메뉴도 제공합니다. 자동 검색 시 Workbench가 설치한 버전까지 비교해 가장 최신 Codex를 선택합니다. 직접 지정한 CLI 경로와 저장한 모델 선택은 유지합니다. 사용 가능한 모델은 계정과 엔진이 제공하는 목록을 따릅니다.
- **프로젝트 삭제**: 프로젝트 우클릭 메뉴와 보관함에서 삭제할 수 있습니다. 확인 후 앱의 프로젝트·대화·검색 기록을 삭제하며, 실제 문서 파일과 작업 폴더는 보존합니다. 실행 중인 작업이나 저장하지 않은 문서가 있으면 삭제를 막습니다.
- **답변 완료 알림**: 메인 채팅과 문서 AI의 실제 완료 이벤트로 알립니다. 앱을 보고 있을 때도 완료 안내와 해당 대화 열기 버튼이 표시됩니다. 데스크톱 알림은 OS 알림 권한과 기존 알림 설정을 따릅니다. 중단·실패는 완료로 알리지 않습니다.
- **문서 AI 병렬 실행**: 문서 탭의 AI 대화와 편집 권한을 탭 수명에 연결했습니다. 다른 문서·메인 세션·프로젝트로 이동해도 작업을 유지하고, 완료 결과는 원래 메인 세션에 전달합니다. 메인 채팅은 별도로 실행할 수 있습니다.

## 검증

- 전체 TypeScript 검사 및 관련 회귀 검사 통과.
- 실제 웹·호스트·이음오피스 편집기를 사용한 통합 검사 11/11 통과: 두 문서의 AI 실행, 숨겨진 탭에서 실제 DOCX 편집·저장, 독립 메인 채팅, 완료 보고·알림, 모델 갱신, 프로젝트 삭제와 원본 파일 보존. 모델 응답은 로컬 시험 서버를 사용했습니다.
- 같은 검사에서 수정 전 탭 연결 코드는 편집 권한을 잃고 두 작업이 중단되는 것을 재현했습니다.
- 로컬 Codex 0.160.0의 실제 `model/list`에서 Sol·Terra·Astra·Luna 계열을 확인했습니다. 모델 이름을 앱에 하드코딩하지 않습니다.
- 릴리즈 Actions는 전체 소스 빌드, 전체 테스트, 같은 문서 병렬 UI 검사, Windows/macOS 신규 설치 및 Windows 0.3.2에서의 데이터 보존 업데이트 검사를 통과해야 설치본을 공개합니다.
