# 0.4.1 — HIG 작업공간과 웹 탭 AI 개선

0.4.0에서 보고된 브라우저 표시·조작 문제를 수정하고, 프로젝트·채팅·문서 작업공간을 Apple HIG와 Pretendard Variable 기준으로 정리했습니다.

- **간단한 시작:** 홈과 빈 웹 탭에서 Search / Ask를 선택합니다. Search는 주소 또는 웹 검색, Ask는 Codex·Claude 작업으로 이어집니다. 새 웹 탭을 열 때 작업공간·프로필 설정부터 요구하지 않습니다.
- **같은 웹 페이지를 AI와 사용:** 오른쪽 위 ‘AI에게 요청’으로 전체 높이의 채팅 패널을 펼치고 접습니다. 요청할 때 해당 웹 세션에 제어가 연결되며 별도의 ‘AI에게 맡기기’를 먼저 누를 필요가 없습니다. 사람이 직접 페이지를 조작하면 제어를 돌려받습니다.
- **브라우저 수정:** 빈 탭 초기화, 탭 복귀 때 크기 적용, iframe 주소가 상단 주소를 덮는 문제, Linux 웹뷰 배치와 앱 메뉴 클릭 차단을 해결했습니다. 입력 성공은 실제 페이지 반영 결과를 확인합니다.
- **병렬 작업:** 웹 AI 대화는 메인 세션과 독립적으로 실행됩니다. 탭 전환 중에도 작업과 페이지 상태를 유지하고 메인 채팅에서 다른 요청을 보낼 수 있습니다.
- **일관된 화면:** 중립적인 라이트/다크 색, 공통 버튼·아이콘·초점, 오프라인 Pretendard Variable을 적용했습니다. 프로젝트의 YAML 개요와 채팅·웹·문서를 구분하고 1·2·4·9분할 및 작업 전달을 제공합니다.
- **읽기와 편집:** 긴 대화·인라인 이미지·갤러리, 편집기 공통 UI를 정리했습니다. 좁은 화면에서는 보조 설정을 기존 메뉴에 모으고 입력창과 승인 버튼이 잘리지 않도록 수정했습니다.

[실제 화면 비교](https://github.com/laguna821/Achmage-workbench-CLI/blob/v0.4.1/docs/design/previews/2026-11-10-finish/index.html) · [구현·확인 범위](https://github.com/laguna821/Achmage-workbench-CLI/blob/v0.4.1/docs/design/2026-11-10-design-finish.md)

Lightpanda 백그라운드 조사는 보이는 웹 탭과 별개입니다. 메인 에이전트가 사람이 볼 페이지를 열 때 공유 웹 탭을 사용합니다. 모든 백그라운드 검색을 자동으로 화면에 복제하지 않습니다.

Windows·macOS·Linux 공통 네이티브 브라우저 핵심 10항목을 확인했습니다. 실제 Codex가 같은 페이지에 입력하고 메인 채팅에 동시에 응답하는 전체 흐름은 Linux에서 확인했습니다. 모든 외부 사이트·실제 계정·AI 공급자 조합을 확인했다는 뜻은 아닙니다.

설치 파일의 출처 커밋·빌드·신규 설치 및 업데이트 결과는 첨부된 `installer-provenance.json`에, 파일별 해시는 `SHA256SUMS.txt`에 기록합니다. 게시 과정에서 설치 파일을 다시 만들거나 기존 공개 파일을 덮어쓰지 않습니다.
