# 0.4.0 — 대화·문서·웹·여러 기기를 한 작업공간에서

이 문서는 통합 설치 후보의 변경 내역입니다. 설치본 생성과 공개 상태는 GitHub Actions 및 해당 파일의 `installer-provenance.json`을 기준으로 합니다.

- **찾기와 프로젝트 이동**: Ctrl+K에서 사용자 프롬프트와 AI 대화 원문을 먼저 보여줍니다. 프로젝트·세션·문서를 구분하고, 공통 생성 메뉴·키보드 이동·초점·대화 읽기 위치와 초안 보존을 정리했습니다.
- **대화와 병렬 작업**: 이미지와 파일을 대화 안에서 확인하고 별도 갤러리로 열 수 있습니다. 메인 세션, 문서 AI, 공급자 하위 작업의 상태·승인·완료 알림과 결과 이동을 연결했습니다. Codex 하위 작업은 실제 thread/turn API를, Claude는 SDK의 중단·백그라운드 전환을 사용합니다.
- **문서 작업**: 9형식 이음오피스 편집기를 개별 탭에서 사용하며 문서 AI를 메인 채팅과 분리합니다. 화면 전환과 실행 권한을 나누고, 독립 실행기·저장·결과 보고·다시 연결하기를 연결했습니다. Dropbox와 별도 이음오피스 설치·같은 파일 열기는 온보딩에서 안내합니다.
- **웹과 외부 앱**: Lightpanda 백그라운드 조사와 별도로, 사람이 보는 웹 탭에서 독립 AI 대화와 제어권 인계를 제공합니다. 다운로드·사이트 권한·프로필을 연결하고, 공식 agent-desktop을 설치해 외부 앱 작업에 사용할 수 있습니다.
- **기기와 백그라운드 실행**: 독립 호스트, 선택 로그인 실행, QR 카메라·이미지 연결, 기기별 프로젝트 승인·철회, 모바일 입력·첨부·공유와 완료 알림을 추가했습니다. Paseo의 보호 전송·터미널·push·음성·확장·Hub 원본 코드를 재사용했습니다.
- **터미널과 서비스 화면**: 작업공간 서버의 실행·출력·종료를 관리하고 실제 웹 화면과 WebSocket을 열 수 있습니다. 로컬은 내장 웹 탭, 원격은 별도 HTTPS preview 주소를 사용합니다.

업데이트 때는 진행 중인 작업과 문서 실행을 확인하고, 데이터 구조 변경 전에 로컬 복구본을 만듭니다. 호환되지 않는 새 클라이언트의 쓰기와 지원 범위를 넘는 데이터베이스 열기를 거절합니다. Windows 설치 프로그램은 기존 백그라운드 호스트가 안전하게 종료된 뒤 설치를 진행합니다.

사용 가능한 기능은 OS·AI 공급자·사용자 계정과 연결 설정에 따라 다릅니다. Claude SDK에 없는 직접 하위 작업 send/steer는 표시하지 않으며, Linux 사이트 권한은 일회성입니다. 원격 서비스 웹 화면에는 별도 HTTPS preview 도메인이 필요합니다.

현재 로컬 통합 근거는 웹·Office·호스트 배포 빌드, Linux 네이티브 실행파일, host/web 타입 확인, 새 HTTP/WebSocket 프록시의 실제 연결·출처 격리·권한 철회 확인입니다. Windows/macOS 설치 및 Windows v0.3.3 데이터 보존 업데이트는 최종 Actions에서 수행합니다. 실제 휴대폰·마이크·외부 계정의 모든 조합을 확인했다는 뜻은 아닙니다.

설치 파일은 한 후보 run에서 만든 6종 파일을 그대로 사용합니다. 시험판과 정식판 모두 출처 commit, 설치에 사용한 파일 hash, 파일 크기와 SHA256SUMS를 확인하며 게시 과정에서 재빌드하지 않습니다. 이미 공개된 릴리즈 파일을 덮어쓰지 않습니다.

후보 CI `42638537165`에서 공통 빌드·전체 타입·1,471개 테스트·실제 UI 11개와 OS별 설치 파일 6종 생성이 통과했습니다. Windows 업데이트 데이터 보존 17개 항목도 통과했지만, 설치본의 agent-desktop 모듈 누락과 이음 공식 저장소 이름 변경으로 신규 설치·종료 확인은 실패했습니다. 두 제품 원인과 선택 앱 안내를 잘못 실패로 판정하던 검사를 수정했습니다. 변경 host의 격리 실행·정상 종료와 이음 출처 경계만 집중 확인했으며, 수정 설치본의 신규 설치·업데이트 결과는 다음 후보 run에서 확인합니다.
