# 워크트리 환경 준비

작업공간 메뉴의 **환경 준비…** 또는 Git 워크트리 생성 기록에서 연다. 개인 설정과 실행할 항목을 선택한 뒤 미리보기의 실제 경로·명령을 확인해 적용한다. 설정 발견이나 새 워크트리 생성만으로 저장소 명령을 실행하지 않는다.

## 설정 출처

| 항목 | 읽는 곳 |
|---|---|
| 준비 명령·기본 터미널·준비 후 AI 시작 | 새 체크아웃의 `orca.yaml` |
| 공유 디렉터리·보관 명령 | 프로젝트에 등록한 원본 체크아웃의 `orca.yaml` |
| 독립 복사 경로 | 원본 체크아웃의 `.worktreeinclude` |
| 개인 명령·공유 경로·Bash 경로·대기 설정 | 이 앱의 로컬 DB, 프로젝트별 별도 판 |

개인 설정의 명령 출처는 YAML만, 개인 설정만, YAML 다음 개인 설정을 지원한다. 자동 선택은 개인 명령이 있으면 개인 설정만 사용한다. 설정 저장은 판 충돌을 확인하며 원본 YAML/include를 쓰지 않는다.

## 파일과 실행

- `.worktreeinclude`는 Git이 무시하는 실제 파일·폴더의 독립 사본을 만든다. 한 줄에 상대 경로 하나를 쓰며 glob·부정 패턴·상위 이동·`.git` 경로는 거절한다. 폴더 내부 링크는 링크로 보존하고 미리보기에 알린다.
- YAML의 `worktree.sharedDirectories`는 기존 gitignored 디렉터리에 대한 링크다. 개인 공유 경로도 링크로 연결한다. 공유 대상 수정은 원본에 영향을 준다.
- 기존 목적지는 유지한다. 원본·설정·목적지가 미리보기 뒤 바뀌면 새 확인이 필요하다. 목적지의 링크를 따라 다른 폴더 안에 새 파일을 쓰지 않는다.
- 복사 후보는 1,000개, 전체 2 GiB·50,000항목까지 확인한다. YAML/include 파일은 256 KiB, 문자열은 64 KiB, YAML 별칭 확장은 100으로 제한한다. 중복 키나 잘못된 YAML은 전체 파일을 거절하고 이유를 표시한다.
- 준비/보관 명령은 작업공간 루트에서 실제 Rust PTY로 실행한다. Bash는 `-e`, Windows는 기본 cmd runner를 사용하며 Git Bash 경로를 지정할 수 있다. `ORCA_ROOT_PATH`, `ORCA_WORKTREE_PATH`, `ORCA_WORKSPACE_NAME`과 원본 경로의 호환 별칭을 전달한다.
- 기본 터미널의 이름·색·명령을 유지한다. 개인 명령만 선택하거나 명령 실행을 끄면 YAML의 탭 명령도 실행하지 않는다. 같은 작업공간의 같은 기본 터미널은 다시 만들지 않는다.
- 준비 후 시작 정책은 준비 성공 또는 명시적 건너뛰기 전의 AI 요청을 막는다. 보관 명령 실패는 보관·제거를 막으며, 표시된 정확한 명령을 명시적으로 건너뛸 수 있다. 외부에서 이미 제거된 체크아웃도 실행 없이 이 확인을 남겨 기록 보관할 수 있다.
- 앱이 만든 그대로의 공유 링크는 Git의 untracked 패치 적용에서 제외한다. 사용자가 바꾸거나 stage한 링크는 정상 변경으로 남는다.

## 중단과 기록

요청 ID로 중복 적용을 막고 파일 단계·명령 터미널·결과를 DB에 남긴다. 취소는 이 준비 작업이 만든 실행에만 전달한다. 큰 파일 하나의 복사가 끝날 때까지 취소 확인이 지연될 수 있다. 실패·취소 때 이미 만들어진 파일을 지우지 않으며, 다음 미리보기는 남은 목적지를 보존한다. 준비 명령의 새 실행은 사용자가 명시적으로 선택한다.

앱 재시작 때 미완료 준비는 중단 상태가 되고 자동으로 명령을 재실행하지 않는다. 보관된 작업공간에서도 준비 기록과 터미널 출력을 볼 수 있다.

## 현재 검증과 남은 동등성

Linux에서 실제 Git/PTY의 복사 격리·공유·경로 검증·설정 CAS·명령 성공/실패/취소·보관 보호·출력 기록을 검사했다. 실제 앱에서는 미리보기·바뀐 원본 거절·실행·공통 기본 탭·한글 출력·실패 후 보관 차단·명시적 건너뛰기·새 포트 재시작을 확인했다.

현재 기본 터미널은 준비 명령이 성공한 다음 만든다. 생성 창을 닫고 백그라운드에서 준비를 마쳤다면 기록에서 결과 탭을 연다. 자동 준비 신뢰 정책, 개인 공유 경로의 macOS APFS clone 선택, shebang 세부 옵션, Windows/macOS 실제 동작과 원격 `environmentRecipes`는 후속 범위다. 이 결과는 전체 O09/Orca 또는 릴리스 완료를 뜻하지 않는다.
